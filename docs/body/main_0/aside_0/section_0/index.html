Defence in Depth

Scriptomatic applies multiple independent security layers so that a failure in any one layer does not expose the site.

  • Capability Gates — every save callback verifies manage_options
  • Dual Nonce Verification — both Settings API and per-location nonces must validate
  • Input Validation — 100 KB cap, invalid UTF-8 rejected, dangerous HTML flagged
  • URL Validation — external URLs validated with wp_http_validate_url()
  • Activity Logging — all saves, rollbacks, and file events recorded
  • Open Redirect Hardening — post-action redirects use admin_url()
  • Singleton Guards — __clone() and __wakeup() prevent duplication
